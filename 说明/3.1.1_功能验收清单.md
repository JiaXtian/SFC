# 3.1.1 多域资源感知与表征：验收清单

## 验收项 1：核心网资源池资源感知与表征
- [ ] 节点包含 `CPU/内存/磁盘/核心网负载` 字段
- [ ] 前端可查看上述资源实时变化
- [ ] 后端推理输入使用上述字段

## 验收项 2：网络拓扑资源与业务SLA感知
- [ ] 节点参数包含 `cpu_available/mem_available/disk_available`
- [ ] 链路参数包含 `status/bandwidth_available/latency/reliability`
- [ ] 业务SLA包含 `min_bandwidth/max_latency/min_reliability`
- [ ] 策略决策轨迹中可看到候选是否满足 SLA

## 验收项 3：采样间隔可配置
- [ ] 存在 `sampling_interval_sec` 配置项
- [ ] 支持范围 `1~30s`
- [ ] 动态拓扑事件按该周期推送（`topology_tick`）

## 验收项 4：星座构型参数表征
- [ ] 元数据包含 `轨道类型/卫星总数/轨道面数/每面卫星数/星间链路数` 等可推导字段
- [ ] 快照中包含 `inclination_deg/altitude_km/raan/true_anomaly`

## 验收项 5：第三方星座构型能力对接
- [ ] 前端支持 JSON 导入第三方构型
- [ ] 后端可接收导入并转为统一拓扑结构
- [ ] 与动态快照模型字段兼容

## 记录项（建议）
- [ ] 使用 4800 星动态场景进行一次完整回放
- [ ] 记录一个拓扑版本序列样例（版本递增、时间连续）
