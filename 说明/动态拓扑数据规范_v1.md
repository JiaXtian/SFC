# 动态拓扑数据规范 v1（TopologySnapshot）

## 1. 目标
统一训练数据、后端推理、前端可视化的动态拓扑字段口径，消除静态/动态两套数据结构差异。

## 2. 顶层字段
- `sim_time`: 仿真时间（ISO8601）
- `topology_version`: 拓扑版本号（单调递增）
- `sampling_interval_sec`: 采样周期（1~30s）
- `metadata`: 星座与版本元数据
- `topology.nodes`: 卫星节点数组
- `topology.links`: 链路数组
- `metrics`: 运行态指标（节点/链路活跃率、平均时延、带宽利用率）
- `events`（可选）: 故障/恢复等事件

## 3. 节点字段
- `id`
- `status`（`active|down`）
- `fault_tag`
- `orbital_params`: `plane/position_in_plane/raan/true_anomaly/altitude_km/inclination_deg`
- `coordinates`: `x/y/z/lat/lon`
- `cpu_total/cpu_available`
- `mem_total/mem_available`
- `disk_total/disk_available`
- `core_network_load`
- `node_reliability`

## 4. 链路字段
- `source/target`
- `link_type`（`intra_orbit|inter_orbit`）
- `status`（`active|congested|down`）
- `latency_ms`
- `bandwidth_gbps/bandwidth_available_gbps`
- `reliability`

## 5. 事件流字段（WebSocket）
- `type=topology_tick`: 全量快照
- `type=metrics_tick`: 轻量指标
- `type=decision_trace`: 策略决策轨迹
- `type=deployment_update`: 部署状态变更
- `type=fault_event`: 故障注入事件
- `type=recovery_event`: 故障恢复事件
